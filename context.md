# DiaperScout Context

DiaperScout is a community-built Explorer's Guide for absorbent products.

Before making changes, read these documents in order:

1. docs/world/
2. docs/spec/
3. docs/architecture/

The World documents are canonical.

The Specification defines product behaviour.

Architecture documents define implementation.

When conflicts occur:

World > Specification > Architecture > Code

Do not invent terminology that conflicts with docs/world/04_Terminology.md.

Do not introduce features that conflict with Discovery Before Commerce.

Always preserve user dignity and trust.
