# DiaperScout World Documentation

## Purpose

This directory defines the identity, philosophy, language, and fictional world of DiaperScout.

It exists to ensure every future design decision, feature, piece of artwork, and line of copy feels like it belongs to the same coherent product.

Rather than inventing ideas repeatedly, this documentation provides a single canonical reference that all project contributors—including humans and AI assistants—can use.

---

## Scope

This documentation covers:

- Project philosophy
- Core principles
- Canonical terminology
- World-building
- Characters and mascots
- Places and organisations
- Lore
- Canon decisions

It deliberately does **not** cover:

- Branding implementation
- User interface design
- Technical architecture
- Backend systems
- APIs
- Source code

Those belong in their respective documentation areas elsewhere in the repository.

---

## Canon

Unless superseded by a later documented decision, the files in this directory represent the canonical source of truth for the DiaperScout world.

Artwork, UI text, marketing material, and product copy should remain consistent with this documentation wherever practical.

---

## Philosophy

DiaperScout is intended to feel like an explorer's guide rather than a shopping catalogue.

It celebrates curiosity, discovery, knowledge, and respect for absorbent products and the people who use them.

Every part of the experience should reinforce that feeling.
